# Frontend — Tienda AIESEC Alumni Bolivia

App React + Vite + Tailwind CSS. Ver instrucciones completas de configuración (Supabase, login con Google, despliegue) en el [README de la raíz del repo](../README.md).

```bash
cp .env.example .env.local   # completar con tus credenciales de Supabase
npm install
npm run dev
```
